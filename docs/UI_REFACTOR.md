# Spoken 全站 UI 重构规范

状态：2026-10-27 已按模块实施并通过本地验收；实机语音与打印验证边界见 `design-qa.md`。

## 1. 设计依据与边界

- 视觉依据：`design/spoken-ui-2026-10-27/index.html`，首页采用其中的 `assets/approved-home.png`；其余页面采用同目录 `screens/*.jpg` 和可交互预览。
- 桌面主视口 1440×900；内容最大宽度 1280px，左右边距约 80px；导航高 82px。宽度不足时收敛间距，900px 以下改为窄屏布局和底部导航。
- 暖奶油纸色 `#fffcf7`、深棕正文 `#342019`、次级文字 `#826b5e`、珊瑚红主操作 `#ff6251`、细分隔线 `#eadfd4`。主按钮白字，辅助按钮细边框。降低阴影、圆角、装饰和卡片嵌套，保持紧凑的分组关系。
- 正文 Microsoft YaHei / Segoe UI / 系统无衬线；标题 32–38px，正文 14–16px。首页展示标题可达 72px，但不能挤压桌面首屏推荐区域。
- 全部界面使用真实 React 文本、表单和按钮；插画只是素材。不得将整张设计截图作为产品界面，也不得把原型示例数据带进真实产品。
- 本次不替换 API、语音协议、评分模型、存储键、身份标识和服务端数据结构；不开展部署配置改动。保留既有路由，并新增 `/scenes` 承接地图。

## 2. 信息架构

桌面主导航：首页、场景练习、Take an Interview、学习工具（生词本 / 每日金句）、学习进度、个人账号。

| 路由 / 状态 | 设计对应 | 变化与必须保留的行为 |
| --- | --- | --- |
| `/` | home | 快速语音练习、场景练习入口、动态推荐与换一个、真实今日目标、每日金句与朗读；地图移出首页 |
| `/scenes` | scenes | 五个主题与现有全部场景，闯关地图与自定义页签、难度/时长/XP、每一关可进入正确场景 |
| `/custom` | custom | 旧地址继续可用，自由描述、中英文、Ctrl/⌘+Enter、示例、一键生成、忙碌与失败重试，生成后进入 `/practice/custom` |
| `/practice/:scenarioId` | voice / call / text | 宽屏对话区与场景侧栏；语音、文字切换不清空对话；现有流式响应与录音链路不变 |
| 对话纠错 | correction | 原句、建议、问题说明、复制、朗读、使用建议切到文字输入；保留转写来源信息 |
| 点词弹层 | dictionary | 音标、词性、释义、例句、朗读、复制、收藏/取消收藏、关闭和错误状态 |
| 跟读弹层 | pronunciation | 录音与识别、整体/准确/流利/完整分数、逐词和音素反馈、重录与失败；只展示有音频依据的评测 |
| 对话语音设置 | voice-panel | 云端/设备/本地三种方式，通话中禁止切换，音色/语速设置入口 |
| `/interview` | interview / question / record / results | Take an Interview 共4题、每题45秒；准备后开始计时、提前提交、转写重试、逐题结果、原回答、点评、范例朗读、重新练习 |
| `/report/:sessionId` | report | 当前练习小结、生成中/失败重试、总分与能力拆解、纠错、表达收藏/取消、建议、PDF打印、重练、进度入口、保存失败重试和幂等保存 |
| `/session/:id` | session | 真实历史记录的小结与完整对话、点词和收藏，错误状态、返回学习进度 |
| `/progress` | progress | 成长洞察、弱项/强项、各维度变化、总分趋势、最近雷达、全部历史记录与详情入口、加载/错误/空态 |
| `/words` | words / sentences / review / review-answer | 单词/短语与句子分组、添加自动释义例句、展开、朗读、掌握、删除、到期复习/未掌握兜底、翻面、记得/忘了、复习完成统计和SRS持久化 |
| `/daily` | daily | 每日5句、五种分类、换一批、AI新句、出处/中文/使用情景、原句搜索、点词、收藏/取消、朗读和跟读 |
| `/me` | profile / profile-guest | 游客与账号态、头像上传、昵称编辑、登录/注册/退出、等级/XP、次数/收藏/连续天数/均分、连续打卡、每日挑战、跟读和访谈历史、12种徽章、重看引导 |
| `/me?tab=voice` | settings | 三种引擎、设备音色、云端音色、场景默认音色、语速、音调、试听、恢复默认；用户旧设置持续有效 |

现有场景目录 `frontend/src/data/scenarios.ts` 是唯一场景来源；主题和关卡不得按原型中的示例硬编码。当前目录中未编入五个主题的场景也必须保留入口。

## 3. 数据和能力保留清单

### 对话和语音

- `Conversation.tsx` 的首次开场、流式增量、失败回复重试、取消请求、路由切换清理、滚动到底部继续有效。
- `lib/call.ts`、`asrStream.ts`、`speech.ts`、`speechStreaming`、`localSpeech/*` 保持协议与状态机。连续通话的倾听/思考/朗读、实时字幕、打断、静音和结束通话不能因布局隐藏。
- 逐句录音和连续通话均保留。识别中禁止重复提交；文字 Enter 发送，提示可填入输入框。麦克风不可用时仍可切文字。
- 云端语音为默认；设备语音为可选；本地模型维持实验性质和首次下载说明。本轮 UI 重构不将语音架构替换为浏览器语音。
- `store/session.ts`、`custom.ts`、`voice.ts` 及现有 localStorage 键不改名、不清空。

### 评分与存储

- 访谈结果是基于转写内容的 /6 练习参考分，不能承诺官方成绩或伪造发音分。
- 对话小结 /100 保持后端返回能力维度，不硬编码示例分。
- 跟读只有实际音频评测才展示发音和音素结果。
- `persistSessionOnce` 与 practiceId 的幂等语义不改；生成成功但保存失败时保留小结并能重试。
- `store/words.ts` 的乐观更新、身份切换、收藏去重、掌握与SRS接口保留。
- 账号 JWT、设备 clientId、游客到账号绑定链路不变；不以新 UI 假设“游客数据只在本地”。

## 5. 验收标准

1. 文档矩阵每行均有可访问入口，原有接口调用与状态可触达；不同主题进入各自的真实场景。
2. 1440×900 与已确认稿对照；同时检查 1280px、1024px 和 390×844，不出现水平滚动、底部遮挡、输入框或主操作不可见。
3. 键盘能访问导航、页签、菜单与弹层；图标按钮有名称，输入有标签，等待与错误有可感知反馈；减少动态效果偏好生效。
4. 真实接口失败时展示可理解的空/错状态；不能用设计示例替代真实数据。测试用 mock 仅存在测试文件。
5. `npm test`、`npm run typecheck`、`npm run lint`、`npm run build` 通过；行为变化增加针对性回归测试。UI样式使用浏览器对照验收，不用实现镜像测试。
6. 浏览器检查主导航、场景目录、自定义、文字对话、访谈状态、词库复习、金句、个人设置；收费/真实AI/麦克风路径通过既有单元测试与明确的人工验证边界，不因缺少凭据谎报已端到端验证。
7. 保存最终视觉验证报告 `design-qa.md`，记录已检查页面、截图、差异、结果；保留可运行预览，清理任务脚本和中间导出。
