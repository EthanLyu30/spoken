# Spoken 私有运行看板

2026-10-30。用户已选择「按推荐的内置方案直接实施」。复用 React、FastAPI、SQLAlchemy、现有登录和 ECharts，不新增外部采集服务。

## 目标和权限

- 由项目所有者观察 Spoken 的延迟、错误、调用量和模型用量，能从异常请求下钻到阶段瀑布图。
- `/admin` 仅作为管理员入口，所有 `/api/admin/*` 读取都必须同时通过现有 JWT 登录和数据库管理员名单校验。游客 401、普通账号 403；不能依赖隐藏菜单或前端状态鉴权。
- 新增管理员关联表，不修改用户密码或既有学习记录。不自动授权第一个账号。通过服务器运维脚本，或适配 Render 免费实例的 `ADMIN_BOOTSTRAP_EMAIL` 一次性配置，按已存在邮箱解析用户 ID 并授权，无公开提权接口。真实邮箱不进入源码、文档示例或构建配置。绑定与消费标记原子入库，账号缺失也消耗标记，未来注册及角色撤销后重启均不重新授权。
- 登录响应只增加当前账号的 `is_admin`，不公开管理员名单；账号退出或切换时清空私有页面数据。

## 方案取舍

选择内置看板：少部署依赖，适配现有语音交互。曾考虑 Langfuse 独立看板，它提供成熟 LLM 可观测能力，但自托管需维护更多服务和存储。本轮不安装外部采集 SDK，不上传用户内容。

## 采集与真实口径

1. 后端：纯 ASGI 中间件记录业务 HTTP 请求，不缓冲 SSE/PCM；结束以最后响应体为准。根请求、DeepSeek、ASR/TTS、连接重试记录各自 span，父子关系和请求 ID 可追踪。
2. SSE 已返回 200 后仍可能失败，记录业务失败状态而非仅看 HTTP 状态。取消单列，不能当作成功或普通服务失败。
3. 模型首文本等待从模型调用开始到首个非空文本 delta；非流式调用没有实测首文本时间，显示缺失。输入/输出 Token 只采用供应商 usage；缺失不记零，不用字符数假装 Token 数。
4. 浏览器：补充直连识别的收尾等待、录音识别总耗时、语音队列首次开始播放等待等。明确标为「浏览器上报」，不能污染可信后端成功率、Token 计量。保持采集白名单、有限载荷与限流；不上报音频、文本、签名 URL、认证头和完整异常消息。
5. 各端使用自己的单调时钟计算耗时。浏览器体验耗时与后端请求瀑布图区分展示，跨机器绝对时间不相减，父子/并发 span 不累计为总时长。
6. 不采集健康探测、登录请求正文、管理员查询和采集接口自身，避免自观测噪声。保留固定路由模板，不保存原始查询字符串。

## 指标与页面

- 概览：请求数、成功率、P50/P95/P99 请求耗时，流式模型 TTFT，错误/超时/取消数。按业务操作、模型、发布版本、时间范围筛选；趋势按操作拆开，避免混合任务得出误导均值。
- 调用链：可按慢请求/异常/Trace ID 筛选。请求详情展示跨度、状态、模型、Token 和安全元数据，瀑布条保留实际重叠，不把父 span 与子 span 相加。
- 用量：供应商报告的输入/输出 Token 与报告覆盖率；费用在缺少可靠价格/计费版本时不展示虚构金额。
- 浏览器体验：单独显示样本数、采集来源和耗时；未上报不推定为零或成功。
- 日期在 API 使用 UTC，页面按 Asia/Shanghai 显示；默认近 24 小时，可选 7 天、14 天。
- 延迟使用 nearest-rank 分位数；样本量与分位数并列，小样本仅供观察。空数据用 `—`，不显示伪造的 0ms/100% 成功。
- 无数据、请求失败、401/403 都有明确页面状态；指标卡、图表、表格受相同过滤条件控制。

## 开销与保留

采集不改变业务响应结构、评分提示词、0–5 分制、历史兼容或模型调用次数。使用有界异步队列、后台批量入库，写入失败或队列拥塞不阻断业务。看板提示采集丢失、写入失败和保留范围；默认保留 14 天，最多 20,000 条，超出保留范围不冒充完整历史。限制请求的 span 数和属性大小。无需大模型对每次调用额外总结。

## 验收

1. 未登录、伪造/过期 JWT、普通账号和伪造前端管理员字段均无法读取概览、列表和详情；只有关联表中指定账号可读。
2. 固定耗时样本独立核对 P50/P95/P99、分母和缺失 Token；取消和流中断被正确分类。
3. 并发请求 span 不串链；采集队列/数据库故障不改变原业务响应；SSE/PCM 不被提前消费或缓冲。
4. 直连语音和本地语音浏览器样本被覆盖并标明来源，恶意字段和过大载荷拒收。
5. 保留策略不触碰原有用户、练习、单词和会话表。所有已有前后端测试、lint、类型检查、构建通过。
6. 验证实际部署的匿名/普通用户拒绝读取。管理员实测取决于可用登录与服务器运维访问；不能用接口定义或构建文件代替真实页面验收。
