# 移动端兼容、学习进度与新版 Interview

## 目标与已确定的方向
- 保持已确认的暖白、珊瑚红、深棕文字与紧凑桌面布局，不重做全站视觉语言。
- 用户确认：Interview 同时保留练习模式与模拟模式，默认练习模式。
- 手机覆盖 320、375、390、430px，平板覆盖 768、900、1024px，桌面验收 1440px；关键内容不溢出，底部导航不遮挡操作。
- 保留场景地图、自定义、语音/文字、历史报告、生词本、金句、登录与语音设置。

## 调查与选择
当前进度页先请求历史，再等最近一次完整报告才退出整页加载；进度路由同步依赖图表库；历史最多 50 条却被当作累计总数；Interview 使用独立观点题加一道 AI 题，缺少主题与来源。

选择局部重构而不是新增产品或更换 UI 框架：现有 React/Zustand/FastAPI 与数据协议继续使用；进度数据分区加载、身份隔离短缓存，图表延迟加载；题库改成来源可追溯的四题主题套组。全量重做会扩大回归范围，纯 CSS 调整则无法解决数据等待与题型问题。

## 学习进度
首屏：标题、刷新、真实累计场景对话/Interview 次数、平均场景分、连续天数与今日目标。主体：练习趋势、能力分析、下一步建议；下方统一历史，可筛选场景与 Interview。场景分 /100，Interview /6，禁止混合计算。

历史返回即可显示；统计、能力与最近报告独立更新。缓存仅存内存，按当前账号/设备隔离，30 秒内回访可立即恢复；保存练习或切换身份后失效。可选请求失败不能让历史整页失败，显式刷新可重试。

## Take an Interview
入口展示主题题组、来源与模式切换；开始前选题组，随机抽整套，不把不相关问题拼凑。保留旧 questions 字段，增加套题元数据与目录端点。默认不调用模型出题。所有来源给出链接、材料性质及核实日期，不声称未经证实的考场真题。

练习：看题、可展开思路提示、听题、开始 45 秒录音，识别后确认转写/重录再进入下一题；可回顾已答题。模拟：先检查麦克风，逐题呈现/听题后自动开始 45 秒，禁止提前显示未来题或无限准备，自动继续下一题；技术失败暂停并允许恢复，反馈仍明确只依据转写。

取消、换题、退出与身份切换必须停止录音、计时、朗读和旧读取/识别/评分请求；识别/评分失败保留已完成回答，允许重试。已按原身份发出的保存请求独立完成，避免正常离开结果页取消保存，也不在换账号后改投新身份。保存练习保留模式、主题、逐题内容，历史中可回顾。

- 用户指定 https://www.youtube.com/watch?v=SCGP0s0UmHE ，已通过公开转写面板核实 #190 写作主题的四道题，加入改编组；时间点见 docs/design-qa-responsive.md，不凭视频标题编造题目。
- YouTube 系列作为外部扩展练习资源，禁止把整个视频系列未经核实地宣称已导入。

## 验收
API 来源与主题一致性、无模型依赖；进度慢报告不阻塞、身份切换和缓存失效；练习/模拟计时与重试；320–1440px 多页/答题/报告/弹窗截图及越界检测。自动合成音频只证明自动录音链路，不替代真实手机麦克风与听感验收。
